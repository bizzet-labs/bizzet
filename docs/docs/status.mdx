# 実装の状況

## このページの目的と範囲

このページは、ETHGlobal Tokyo 2026 の期間中（2026年9月25日〜27日）に、ベータ版の機能のうち何を作り、何をまだ作っていないかを、機能 ID と画面 ID ごとに示します。扱うのは各機能と画面の実装の状態と、それをどう確かめたかだけで、機能や画面の中身、設計の考え方はこのページでは扱いません。状態は「実装済み」「一部」「実装中」「未実装」の4つで表し、「一部」のものは足りない部分を表の下に書きます。「実装中」は、期間中に作っている最中で、まだ動くことを確かめていないものを指します。

## まとめ

ダッシュボードの機能と、ウォレットの土台になるオンチェーンの部品（Safe、パスキーの署名者、Roles v2 の設定）はでき上がっており、Sepolia のフォークと実際の Sepolia の両方で動きを確かめました。一方で、客が支払う流れ、レシート、ウォレットでの承認への署名、署名がそろった取引の中継での送信はまだ作っていないため、出金の提案は作れても実行までは進みません。ENSv2 の組み込みは Sepolia で進めている最中で、まだ動くことは確かめていません。自動テストは、vitest（ダッシュボード 11件、ウォレット 2件）とコントラクトのフォークテスト 5件がすべて通り、型チェックも通っています。
