# 機能一覧

ベータ版で作る機能を、ID を付けて一覧にします。機能は、ウォレット・ダッシュボード・値札と決済の3つに分けます。各機能を、誰が使い、どの画面や部品で実現するかも示します。ベータ版で扱わない機能は、最後の「ベータ版で扱わないもの」にまとめます。

## ウォレット

メンバーが自分のウォレットを使う機能と、その裏で動くオンチェーンの機能です。

| ID | 機能 | 使う人 | 実現する場所 |
| --- | --- | --- | --- |
| W-01 | パスキーの登録と、ウォレットの画面へのログイン | すべてのメンバー | ウォレットの画面 |
| W-02 | 自分のグループの残高の確認 | すべてのメンバー | ウォレットの画面 |
| W-03 | 送金（出金の作成） | Owner、Approver | ウォレットの画面 |
| W-04 | 出金の承認への署名 | Owner、Approver | ウォレットの画面 |
| W-05 | 2人承認での出金の実行 | — | Safe |
| W-06 | 別のチェーンの売上の、本部のウォレットへの移動と、受け取る通貨への交換 | — | Sweep、キーパー |

## ダッシュボード

ロールと所属グループに合わせて、残高・出金・メンバーを見る機能です。

| ID | 機能 | 使う人 | 実現する場所 |
| --- | --- | --- | --- |
| D-01 | メールアドレスとパスワードでのダッシュボードへのログイン | すべてのメンバー | ダッシュボード |
| D-02 | 見られるグループの残高の一覧 | すべてのメンバー | ダッシュボード |
| D-03 | 入金の履歴の確認 | すべてのメンバー | ダッシュボード |
| D-04 | 出金の状況の確認 | Owner、Approver | ダッシュボード |
| D-05 | メンバーの追加と、グループ・ロールの割り当て | Owner | ダッシュボード |
| D-06 | ブリッジ待ちの売上の確認 | すべてのメンバー | ダッシュボード |
| D-07 | 店舗のグループの作成と、グループの Safe の設定 | Owner | ダッシュボード |
| D-08 | もう一方のログイン手段（パスキー）を追加するリンクの発行 | すべてのメンバー | ダッシュボード |
| D-09 | 表示言語（日本語・英語）の切り替え | すべてのメンバー | ダッシュボード |

D-05 の招待の発行とグループ・ロールの割り当ては Owner 1人で行えます。そのうち本部の Safe のオーナーが増減する変更は、Safe のオーナー変更の提案として作られ、本部の2人承認で実行されます。D-07 の本部のグループは初期セットアップで作り、店舗のグループは本部の Owner がダッシュボードで作ります。

## 値札と決済

客が払い、売上が店舗のウォレットに入るまでの機能です。

| ID | 機能 | 使う人 | 実現する場所 |
| --- | --- | --- | --- |
| P-01 | JPYC と USDC での価格の表示 | 客 | 値札、購入ボタン |
| P-02 | QR か NFC での支払いの受け付け | 客 | 値札、購入ボタン、Checkout コントラクト |
| P-03 | 決済時の、受け取る通貨への交換 | — | Checkout コントラクト |
| P-04 | 「処理中」と「済」の表示 | 客 | 値札、購入ボタン |
| P-05 | 商品と価格の登録 | 仮置き | 仮置き |
| P-06 | 受取先と受取通貨の設定 | Owner | ENSv2 のテキストレコード |
| P-07 | 支払いと同時の、レシートの識別子の登録 | 客 | 決済ページ、Checkout コントラクト、Semaphore v4 |
| P-08 | 買った記録による割引（同じ商品を前に買った客に1回だけ） | 客 | 決済ページ、Checkout コントラクト、Semaphore v4 |

## 決まっていないこと

- **W-03 の送金の作成者**：仮置き。権限管理のパーミッションには「出金の作成」がないため、Safe のオーナーである Owner と Approver が作成できる前提にしています。パーミッションを決めた時点で更新します。
- **P-05 の使う人と場所**：仮置き。値札に出す価格を、誰がどの画面で登録するかを決めた時点で更新します。権限管理の最小構成には「価格変更」のパーミッションがありません。
- **パスキーの紛失時の入れ替え**：ベータ版で扱うかを決めていません。

## ベータ版で扱わないもの

| 機能 | 理由 |
| --- | --- |
| 条件つき価格（数量・時間帯） | 最初に作るのは値札1台の基本の流れのため |
| 買った記録の回数と期間の条件 | 集合に入っていることの証明では表せないため |
| Sui と Kaia での受け取り | CCTP v2 が未対応のため |
| 経費の出金と、その上限 | 権限管理を最小構成にしたため |
| 台帳と仕訳 | 機能から外したため |
