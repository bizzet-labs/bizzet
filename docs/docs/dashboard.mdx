# ダッシュボード

## 何を解くか

Safe 公式の画面は Safe ごとの操作が前提で、本部と店舗のグループや、メンバーのロールに沿った見え方になりません。ダッシュボードは、bizzet のインデクサーが集めたオンチェーンの情報を、メンバーのロールと所属グループに合わせて見せる画面です。

## できること

| 画面 | 何ができるか | 使えるロール |
| --- | --- | --- |
| 残高 | 本部・店舗ごとのウォレットの残高と入金の履歴の確認 | Owner、Approver、Viewer |
| 出金 | 出金の作成、承認の状況の確認、送信前の却下 | Owner、Approver |
| グループ | 店舗の追加と、グループの Safe の設定の確定 | Owner |
| メンバー | メンバーの招待・編集・削除、グループへの所属、ロールの付与 | Owner |
| アカウント | 自分の情報の確認と、パスキーの追加用リンクの発行 | Owner、Approver、Viewer |
| ブリッジの状況 | 別のチェーンから本部のウォレットへ移動中の売上の確認 | Owner、Approver、Viewer |

出金の承認の署名は、パスキーを使うウォレットの画面で行います。ダッシュボードはメールアドレスとパスワードでログインするため、署名はできません。

見られる範囲は、ロールを付与されたグループとその配下に限られます。店舗の Viewer は自分の店舗の残高だけを、本部の Owner は全店舗の残高を見られます。

## 設計の選択

- **閲覧の制御は画面側に置く。** 閲覧はオンチェーンで強制せず、ダッシュボードがロールと所属グループに合わせて表示を絞ります。
- **データは bizzet のインデクサーから取る。** Safe 公式の Transaction Service には依存しません。入金の履歴は、グループの Safe に入った JPYC と USDC の送金をチェーンから取り込んで持ちます。取り込みは、ホームとグループ詳細を開いたときに数秒の上限つきで前回の続きから進め、誰も画面を開かない間は定期実行（Vercel Cron）で進めます。
- **残高はチェーンから直接読む。** 残高は画面を開くたびにチェーンから読み、読めなかった場合は合計を出さずにエラーを表示します。取り込みの遅れで残高がずれて見えることを防ぐためです。
- **ブリッジ待ちを残高と分けて見せる。** ブリッジの到着が遅れても、資金が消えたのではなく移動中であることが分かるようにします。ベータ版は自動ブリッジを動かさないため、ブリッジの状況の画面は空の状態だけを出します。
- **日本語と英語に対応する。** 表示言語は、メンバーが画面で選んだ言語（Cookie に保存）、ブラウザの言語設定、日本語の順に決めます。URL に言語を含めないため、同じリンクを言語の違うメンバーに共有できます。
