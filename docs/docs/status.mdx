# 実装の状況

## このページの目的と範囲

このページは、ETHGlobal Tokyo 2026 の期間中（2026年9月25日〜27日）に、ベータ版の機能のうち何を作り、何をまだ作っていないかを、機能 ID と画面 ID ごとに示します。扱うのは各機能と画面の実装の状態と、それをどう確かめたかだけで、機能や画面の中身、設計の考え方はこのページでは扱いません。状態は「実装済み」「一部」「未実装」の3つで表し、「一部」のものは足りない部分を表の下に書きます。

## まとめ

ダッシュボードの機能と、ウォレットの土台になるオンチェーンの部品（Safe、パスキーの署名者、Roles v2 の設定、ENSv2 の名前とレコード）はでき上がっており、Sepolia のフォークで動きを確かめました。本部の Safe の出金は、ウォレットでのパスキーの署名から実行まで通るようになり、客は値札の QR から ENS の名前で受取先を解決して JPYC か USDC で支払えます。一方で、店舗の Safe の提案への署名、決済時の交換、レシート、Checkout コントラクトはまだ作っていません。自動テストは、vitest（ダッシュボード 11件、ウォレット 21件）とコントラクトのフォークテスト 13件がすべて通り、型チェックも通っています。

| P-03 | 決済時の交換 | 未実装 | — |

決済ページは、値札の QR が指す店舗の ENS の名前を Universal Resolver で解決し、客のブラウザのウォレットから受取先へ ERC-20 を送ります。P-01 は USDC の価格をデモ用の固定レートで換算しており、P-02 は QR だけで NFC には対応していません。P-04 は、客のウォレットからの実際の送金ではまだ試していません。P-06 は、店舗の追加とグループの設定から ENS に書き込みますが、実際の Sepolia での本部の名前の登録はまだ行っていません。P-03、P-05、P-07、P-08 は、Checkout コントラクトと Semaphore との連携を作っていないため未実装です。

## オンチェーンの部品

| 部品 | 状態 | 確かめた方法 |
| --- | --- | --- |
| Safe の設定と CREATE2 でのアドレスの計算 | 実装済み | フォークテストでの、デプロイ済みの Safe とのアドレスの一致 |
| パスキーの署名者と ERC-4337 の UserOperation | 実装済み | フォークテストでの `handleOps` の通しの実行と、Sepolia での実際の送信 |
| SafeTx のハッシュの計算 | 実装済み | フォークでの、Safe の `getTransactionHash` との一致 |
| Roles v2 の設定 | 実装済み | フォークテストでの、キーパーが本部の Safe への送金しかできないことの確認 |
| ENSv2 の組み込み（本部の名前、店舗のサブネーム、受取先のレコード） | 実装済み | フォークテストでの、登録・レコードの書き込み・解決の確認 |
| 署名がそろった取引の送信 | 一部 | フォークテストでの、1つの UserOperation での Safe の配置と execTransaction |
| Checkout コントラクト | 未実装 | — |
| Semaphore v4 との連携 | 未実装 | — |

パスキーの署名者と ERC-4337 については、Pimlico を通した実際の Sepolia での UserOperation で、ガス代を肩代わりしてもらいながら Safe と署名者をデプロイできたことを確かめました。その取引のハッシュは 0xe1bfcc2134d73fb42c8c8b7e26c7581baeec14ad02d4f0764e610008ab5ca6c4 で、Sepolia の Etherscan（https://sepolia.etherscan.io/tx/0xe1bfcc2134d73fb42c8c8b7e26c7581baeec14ad02d4f0764e610008ab5ca6c4 ）で確かめられます。
