# 設計

このページは、bizzet のベータ版を作るための設計をまとめます。

## 前提

| 項目 | 内容 |
| --- | --- |
| 対象 | ベータ版 |
| ホームチェーン | Ethereum Sepolia |
| 客が払うチェーン | Ethereum Sepolia だけ |
| 対応する通貨 | JPYC、USDC |

## 構成要素

| 構成要素 | 役割 | 置き場所 |
| --- | --- | --- |
| Safe | 本部・店舗ごとの資金の保管と、2人承認 | オンチェーン |
| Zodiac Roles v2 | ロールとパーミッション、宛先を固定したキーパーのロール | オンチェーン |
| パスキーの署名者 | メンバーのパスキーを Safe のオーナーとして扱う | オンチェーン |
| 中継用アカウント（Safe と Safe4337Module） | 署名がそろった Safe の取引の送信と、ガス代の肩代わりの受け口 | オンチェーン |
| Checkout コントラクト | 支払いの受け付け、交換、割引の判定、`Paid` の発行 | オンチェーン |
| Semaphore v4 | レシートの集合と、買った記録の証明の検証 | オンチェーン |
| Sweep | 店舗の Safe の売上を、本部の Safe へ移す | オンチェーン |
| バンドラー、Paymaster、キーパー | 取引の送信、ガス代の肩代わり、Sweep の起動 | 外部のサービス |
| バックエンド | メンバー・招待・提案・署名の保管、入金の取り込み（インデクサー） | オフチェーン |
| ウォレットの画面 | メンバーがパスキーでログインし、署名する | オフチェーン |
| ダッシュボード | ロールと所属グループに合わせて、残高・出金・メンバーを見る | オフチェーン |
| 値札と購入ボタン | 価格の表示と支払いの受け付け、「済」の表示 | オフチェーン |
