# About bizzet

"A wallet, for business."

bizzet is a project that rebuilds how businesses receive and manage money using stablecoins and smart contracts, cutting out intermediaries and letting revenue reach the business directly.

## The big picture

Customer payments go straight into each store's wallet, so accepting them needs no register, payment processor, or wait for funds to settle. From there, revenue is collected into the headquarters wallet.

## Features built for business

While most wallets are built for individuals, the bizzet wallet has the following features that businesses need.

- **User management**: add members and assign them to headquarters or store groups
- **Permission management**: assign Owner, Approver, and Viewer roles per group, and set policies such as requiring approval from both an Owner and an Approver for a withdrawal
- **Automatic bridging**: revenue paid on a different chain automatically moves to the headquarters wallet
