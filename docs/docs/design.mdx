# 設計

このページは、Bizzet のベータ版を作るための設計をまとめます。

## 前提

| 項目 | 内容 |
| --- | --- |
| 対象 | ベータ版 |
| ホームチェーン | Ethereum Sepolia |
| 客が払うチェーン | Avalanche Fuji、Polygon Amoy（任意） |
| 対応する通貨 | JPYC、USDC |

## 構成要素

| 構成要素 | 役割 | 置き場所 |
| --- | --- | --- |
| Safe | 本部・店舗ごとの資金の保管と、2人承認 | オンチェーン |
| Zodiac Roles v2 | ロールとパーミッション、宛先を固定したキーパーのロール | オンチェーン |
| パスキーの署名者、Safe4337Module | パスキーでの署名と、ガス代の肩代わり | オンチェーン |
| Checkout コントラクト | 支払いの受け付け、交換、`Paid` の発行 | オンチェーン |
| Sweep | 別のチェーンの売上を、本部のウォレットへ移す | オンチェーン |
| インデクサー | オンチェーンの情報を集め、画面に渡す | オフチェーン |
| ウォレットの画面 | メンバーがパスキーでログインし、署名する | オフチェーン |
| ダッシュボード | ロールと所属グループに合わせて、残高・出金・メンバーを見る | オフチェーン |
| 値札と購入ボタン | 価格の表示と支払いの受け付け、「済」の表示 | オフチェーン |
