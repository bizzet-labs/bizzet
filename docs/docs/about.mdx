# About bizzet

「ビジネスのための、ウォレット。」

bizzet は、ビジネスがお金を受け取り、管理するまでの仕組みをステーブルコインとスマートコントラクトでつくり直すことで、間に立つ人や仲介を減らし、売上がそのままビジネスの手元に届くようにするプロジェクトです。

## 全体像

客の支払いは各店舗のウォレットに直接入るため、受け取りにレジ・決済代行・入金待ちは要りません。売上はそこから本部のウォレットに集まります。

## ビジネス向けの機能

多くのウォレットが個人向けであるのに対し、bizzet のウォレットはビジネスに必要な次の機能を備えています。

- **ユーザー管理**：メンバーを追加し、本部・店舗のグループに所属させられる
- **権限管理**：グループごとに Owner・Approver・Viewer のロールを割り当て、出金には Owner と Approver の2人の承認を求めるといったポリシーを設定できる
- **自動ブリッジ**：別のチェーンで払われた売上も、自動で本部のウォレットに移る
