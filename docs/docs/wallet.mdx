# Wallet for Biz

Wallet for Biz（ビジネス向けウォレット）は、ビジネスの売上を受け取り、保管し、送金するためのウォレットです。

## 何を解くか

店舗は売上を受け取り、複数人の承認なしには動かせない形で保管したいと考えます。個人向けウォレットには「誰が出金できるか」の概念がなく、決済代行を挟めば審査と手数料がかかるため、bizzet は承認と権限を備えたビジネス向けウォレットで売上を受け取ります。

## 考え方

- **資金に触れるのはウォレットだけ。** 値札や購入ボタンは鍵を持たず支払いを受け付けるだけなので、端末を盗まれても売上には届きません。
- **グループごとにウォレットを持つ。** 本部と店舗がそれぞれウォレットを持ち、店舗の売上は本部のウォレットに集まります。
- **オンチェーンで強制するのは資金に関わる操作だけ。** 出金や権限の付与はオンチェーンで強制し、閲覧や人事の情報は画面側に置きます。
- **土台に依存しない設計にする。** アカウント・承認・権限・自動ブリッジを bizzet 側の抽象として定義し、土台の Safe はその実装の1つとして扱います。土台を差し替えても、ダッシュボードや値札は変えずに済みます。

## ウォレットの基本

本部と店舗はそれぞれ自分のウォレットを持ち、売上は各店舗のウォレットに直接入るため、決済代行の口座や入金待ちを通りません。受け取った売上は、通常のウォレットと同じく残高を確認し、送金できます。送金は、次の「ビジネス向けの機能」の権限管理で決めたロールとポリシーに従います。

対応する通貨は JPYC と USDC で、ビジネスはどちらで受け取るかを選べ、客がもう一方で払っても決済のときに交換されます。

画面は、ウォレットとダッシュボードの2つに分かれます。ウォレットの画面はメンバーが自分のウォレットを使うためのもので、ダッシュボードは、ロールと所属グループに合わせて残高・出金・メンバーを見るための画面です。

## ビジネス向けの機能

個人向けウォレットにない、次の5つの機能を備えています。

| 機能 | 何ができるか |
| --- | --- |
| ユーザー管理 | メンバーの招待と、本部・店舗のグループへの所属 |
| 権限管理 | グループごとのロールの割り当てと、出金などのポリシー |
| パスキー | ウォレットの画面での、メンバーごとのパスキーによるログインと署名 |
| ダッシュボード | ロールと所属グループに合わせた、残高・出金・メンバーの画面 |
| 自動ブリッジ | 別のチェーンで払われた売上の、本部のウォレットへの自動の移動（本番から） |

## 土台の技術

ウォレットの土台は、監査済みの Safe と Zodiac Roles v2 を bizzet 自身が配置して使います。Safe への依存は設計上のものではなく配置上のもので、コードは LGPL で公開されているため、Safe 公式が対応していない EVM チェーンにも自分で配置できます。

| 部品 | 役割 |
| --- | --- |
| Safe（グループごとに1つ、本部はしきい値 2） | 資金の保管と2人承認 |
| Zodiac Roles v2 | 店舗の Safe で、宛先を本部の Safe に固定したキーパーのロール |
| Safe のパスキーの署名者（v0.2.1） | メンバーのパスキーを Safe のオーナーとして使う |
| Safe4337Module（v0.3.0） | bizzet の中継用アカウントによる、ERC-4337 での取引の送信とガス代の肩代わり |

パスキーの署名者は Certora・Nethermind・Hats、Safe4337Module は Ackee・Certora・Nethermind の監査を受けており、いずれも未解決の指摘はありません。どの部品も、監査を受けたコミットのまま配置します。コードを少しでも変えると、監査の対象外になるためです。

メンバーは Safe の取引にパスキーで署名するだけで、チェーンへの送信は bizzet の中継用アカウントが行い、ガス代は Paymaster が肩代わりします。インデクサーと画面は bizzet が持つため、Safe 公式の Transaction Service や Safe\{Wallet\} には依存しません。ベータ版のホームチェーンである Ethereum Sepolia には、Safe と Roles v2 の両方が配置済みです。
