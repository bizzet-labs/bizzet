# ダッシュボード

## 何を解くか

Safe 公式の画面は Safe ごとの操作が前提で、本部と店舗のグループや、メンバーのロールに沿った見え方になりません。ダッシュボードは、bizzet のインデクサーが集めたオンチェーンの情報を、メンバーのロールと所属グループに合わせて見せる画面です。

## できること

| 画面 | 何ができるか | 使えるロール |
| --- | --- | --- |
| 残高 | 本部・店舗ごとのウォレットの残高の確認 | Owner、Approver、Viewer |
| 出金 | 出金の承認 | Owner、Approver |
| メンバー | メンバーの追加、グループへの所属、ロールの付与 | Owner |
| ブリッジの状況 | 別のチェーンから本部のウォレットへ移動中の売上の確認 | Owner、Approver、Viewer |

見られる範囲は、ロールを付与されたグループとその配下に限られます。店舗の Viewer は自分の店舗の残高だけを、本部の Owner は全店舗の残高を見られます。

## 設計の選択

- **閲覧の制御は画面側に置く。** 閲覧はオンチェーンで強制せず、ダッシュボードがロールと所属グループに合わせて表示を絞ります。
- **データは bizzet のインデクサーから取る。** Safe 公式の Transaction Service には依存しません。
- **ブリッジ待ちを残高と分けて見せる。** ブリッジの到着が遅れても、資金が消えたのではなく移動中であることが分かるようにします。
- **日本語と英語に対応する。** 表示言語は、メンバーが画面で選んだ言語（Cookie に保存）、ブラウザの言語設定、日本語の順に決めます。URL に言語を含めないため、同じリンクを言語の違うメンバーに共有できます。
